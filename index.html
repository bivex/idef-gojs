Architecture (DDD-HEX)

Hexagonal (Ports & Adapters):

  • Domain: Pure TypeScript Aggregate Root (IDEF1Model), Entities, Value Objects, Domain Events, Invariants.
  • Ports: IIDEF1EditorUseCase (driving), IDiagramRendererPort (driven).
  • Adapters: GoJSDiagramAdapter, InMemoryOrJsonRepository, IDEF1Editor facade.

IDEF1X Standard Notation

  • Square corners: Independent entity
  • Rounded corners: Dependent entity
  • Solid line: Identifying relationship
  • Dashed line: Non-identifying relationship
  • Dot + 'P': Cardinality (1 or more)
  • Subtype circle: Categorization cluster
